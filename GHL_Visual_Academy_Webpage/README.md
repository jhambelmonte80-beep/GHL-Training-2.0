# GHL Visual Academy — Web Edition

A static, GitHub Pages-ready interactive learning site for the GoHighLevel Visual Academy. All lesson notes and client missions are displayed inside the website; no PowerPoint files are required.

## Features
- 31 curriculum modules
- 599 client missions extracted from the source training modules
- Module navigation, search, category filters and reverse-order option
- Feature overview and instructional page maps
- Click-by-click mission instructions and verification steps
- Task-specific YouTube search links for every scenario
- A few curated videos embedded where a specific video was verified
- Progress tracking saved in browser localStorage
- Responsive design, no framework/build needed

## GitHub Pages deployment
1. Extract this folder.
2. Upload `index.html`, `data.js`, and `README.md` to the root of a GitHub repository.
3. Repository Settings → Pages.
4. Select Deploy from a branch, `main`, root folder, Save.

## Important video note
Scenario links open YouTube search results with the exact request as search terms. This is intentional: there is no verified, unique video for every scenario. Curated video cards are labeled as verified and are provided only where a specific tutorial was located.

## Interface visuals
The UI page maps are reconstructed training visuals—not screenshots from a live authenticated GHL account. Menus may vary by account, plan, permission and product rollout.
